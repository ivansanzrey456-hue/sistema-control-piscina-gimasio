# Sistema de Control de Accesos y Membresías

Sistema web para el control de entradas y salidas, gestión de socios, pagos diarios y membresías.
---

## 🧩 Tecnologías utilizadas

- Frontend: React
- Backend: PHP
- Base de datos: MySQL
- Servidor local: AppServer

---

## ✨ Funcionalidades principales

- Registro y autenticación de usuarios
- Control de accesos (entradas y salidas)
- Gestión de socios
- Pagos diarios y pagos por membresía
- Roles de usuario (admin / encargado)

---
